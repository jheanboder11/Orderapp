# Orderapp: tu carpeta del proyecto

## Qué hay aquí
| Archivo / carpeta | Para qué sirve |
|---|---|
| **PLAN-orderapp-nextjs.md** | El plano de la app. Claude Code lo sigue fase por fase |
| **CLAUDE.md** | Instrucciones que Claude Code lee solo, cada vez que abre la carpeta |
| **docs/funciones.md** | Qué hace la app hoy (documento vivo) |
| **docs/agents.md** | Cómo te gusta que se construyan las cosas |
| **referencia/** | La versión que ya tenemos: Code.gs, Index.html y la demo (demo/index.html). **No se edita** |
| **.env.example** | Plantilla de las "llaves" secretas (se copia a .env.local) |
| **.gitignore** | Lista de lo que NUNCA se sube a GitHub |
| **app/** | (Aparece cuando Claude Code empiece) El código nuevo de la app |

## Cómo empezar (paso 2)
1. Abre Claude Code en esta carpeta.
2. Pégale: *"Lee CLAUDE.md y construye la Fase 0. Al terminar, súbela a mi GitHub (repositorio orderapp, privado) y explícame qué hiciste."*
3. Revisa, y cuando funcione: *"Fase 0 revisada, haz la Fase 1."*
