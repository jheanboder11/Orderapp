# Orderapp: tu carpeta del proyecto

## Qué hay aquí
| Archivo / carpeta | Para qué sirve |
|---|---|
| **PLAN-orderapp-nextjs.md** | El plano de la app. Claude Code lo sigue fase por fase |
| **CLAUDE.md** | Instrucciones que Claude Code lee solo, cada vez que abre la carpeta |
| **docs/funciones.md** | Qué hace la app hoy (documento vivo) |
| **docs/agents.md** | Cómo te gusta que se construyan las cosas |
| **docs/estado.md** | Dónde vamos, qué sigue y qué riesgos hay (la "bitácora") |
| **docs/analisis-piloto.md** | Plantilla para analizar los datos del piloto de 2 semanas |
| **docs/archivo/** | Documentos viejos (versión Apps Script), solo para consulta |
| **referencia/** | La versión que ya tenemos: Code.gs, Index.html y la demo (demo/index.html). **No se edita** |
| **.env.example** | Plantilla de las "llaves" secretas (se copia a .env.local) |
| **.gitignore** | Lista de lo que NUNCA se sube a GitHub |
| **app/** | El código nuevo de la app (Next.js) |
| **contexto-jhean.md** | Tu contexto (negocios, prioridades, cómo hablarte). Claude lo lee y lo actualiza. Viaja entre tus PCs por GitHub |
| **.claude/settings.json** | Hace que Claude traiga lo último de GitHub cada vez que lo abres |

## Cómo seguir
1. Abre Claude Code en esta carpeta.
2. Dile: *"Lee docs/estado.md y sigamos."*
3. Al terminar cada fase, revisa, y cuando funcione: *"Fase X revisada, haz la siguiente."*
